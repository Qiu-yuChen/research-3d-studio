QUICK START

From folders to paper figures

  1. Choose one or more workspaces. Compare each workspace as a group, or group by one to three subfolder levels.
  2. Matching models line up automatically. Missing methods stay empty; unmatched and conflicting names remain grouped by folder. You can change the matching rule.
  3. Click “Compare row” for synchronized views. Page through more than four methods, and add any number of models to the export queue.
  4. Adjust the camera, axes, and lighting. Original color, relighting, and data passes remain separate.
  5. Download a single image, or batch-export models, views, and passes.
  6. Save settings as a project JSON, or pack a project ZIP that includes the files.

Metrics CSVs use path, sample, method, category, prompt, and custom numeric columns. Δ pairs by sample and requires exactly one valid score for each method.

Folder connections depend on browser support. Chrome / Edge can retain folder handles and rescan; other browsers use snapshots that must be reimported after changes. Project JSON does not include model files.

Gaussian splats have no reliable surface material. Pair a mesh for normals and relighting. Rendered pixels may vary slightly across devices.
